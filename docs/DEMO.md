# 60 秒演示脚本

目标：让观众在 60 秒内看懂"输入 → 评分 → 定制内容 → 导出"这条闭环。

## 录制前准备

1. `npm run dev` 已启动，浏览器打开 `http://localhost:3000`。
2. **先跑一次完整分析**（预热模型与连接，避免录制时首次请求超时或等待过久），然后刷新页面——历史记录里会留下一条，正好用来演示。
3. 浏览器窗口尺寸设为 **1440×900**，缩放 100%；录屏区域只截浏览器内容区（不含书签栏与桌面）。
4. 主题切到 **暗色**（右上角太阳/月亮按钮），录制观感更好。
5. 关闭消息通知、静音麦克风（若配旁白请单独录）。

推荐工具：Windows 用 Xbox Game Bar（`Win + G`）或 ShareX；macOS 用 `Cmd + Shift + 5`。输出 1440×900、30fps、MP4，再转 GIF：

```bash
# 需要 ffmpeg
ffmpeg -i demo.mp4 -vf "fps=15,scale=1000:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" -loop 0 docs/demo.gif
```

## 分镜（总时长 60 秒）

| 时间 | 画面动作 | 旁白 / 字幕要点 |
| --- | --- | --- |
| 0:00-0:05 | 停在首页，鼠标轻扫两栏布局 | "求职时最累的不是投递，是为每个岗位重写同一段经历。" |
| 0:05-0:08 | 点击 **「填入示例，直接体验」** | "先看一遍完整流程——这里用示例数据。" |
| 0:08-0:16 | 滚动到左侧 JD 卡片，展示文字与 `字数` 徽章；点「示例」按钮演示可替换 | "左边粘贴完整 JD，含任职要求和加分项。" |
| 0:16-0:24 | 切到右侧「上传文件」页签，把示例 PDF 拖进虚线框；再切回「粘贴文本」 | "右边上传 PDF / DOCX，或者直接粘文本。文件在服务端内存里解析完就释放，不落库。" |
| 0:24-0:28 | 点击 **「开始分析」**，出现进度卡（阶段文案 + 已用秒数） | "点开始，四步流水线：解析、匹配、生成。" |
| 0:28-0:38 | 结果区出现：**环形评分**从 0 动画到分数；鼠标移到维度条上；滚过绿/黄/红标签 | "总分 100 分制，拆成技能覆盖、经验相关、关键词、教育年限四个维度。" |
| 0:38-0:44 | 展开一条强匹配点与一条缺失技能，**停 1 秒让观众看清「简历 / JD」来源标签** | "每条结论都标了来源——来自简历哪一段、JD 哪一条。" |
| 0:44-0:52 | 切到 **「定制 Bullet」** 页签，逐条滚动，指一下 XYZ 与「原始表述」 | "定制 Bullet 用 XYZ 句式：通过什么做法、实现什么结果、带来什么价值。只重组，不编造。" |
| 0:52-0:57 | 切到 **「Markdown / 导出」**，点 **「复制 Markdown」**（toast 弹出），再点 **「下载 .md」** | "一键复制 Markdown，或者下载、打印成 PDF。" |
| 0:57-1:00 | 点顶部 **「历史记录」**，展示刚保存的记录，鼠标停在删除按钮 | "最近 10 次分析自动存本地，随时可以删。" |

## 剪辑要点

- 全程**不加转场特效**，用鼠标移动引导视线；分析等待段做 2-4 倍速处理即可（保留进度卡的阶段文案）。
- 字幕不要压在评分环或红黄绿标签上。
- GIF 体积控制在 **5MB 以内**（fps 15、宽度 1000px 足够）。
- 封面帧建议取 0:28-0:38 的结果区，评分环 + 三色标签最能说明价值。

## 录完替换

```bash
cp demo.gif docs/demo.gif
```

然后确认 `README.md` 中的 `![JobFit AI 演示](docs/demo.gif)` 正常渲染。
